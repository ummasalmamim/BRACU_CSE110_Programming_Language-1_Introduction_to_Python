**Author:** Umma Salma Mim

## About the Course

CSE110 introduces the foundations of programming, including control structures, string manipulation, arrays, and basic debugging. By the end of the course, students are expected to be able to:

- Create flowcharts, and write, debug, and run programs.
- Apply branching and looping structures to control program flow.
- Manipulate text using string operations.
- Create, modify, and sort arrays to store and process data.

## Getting Started

**Requirements:** [Python 3](https://www.python.org/downloads/), [Git](https://git-scm.com/downloads), and Jupyter Notebook.

```bash
# Clone the repository
git clone https://github.com/ummasalmamim/BRACU_CSE110_Programming_Language-1_Introduction_to_Python.git
cd BRACU_CSE110_Programming_Language-1_Introduction_to_Python

# Install and launch Jupyter
pip install notebook
jupyter notebook
```

Open any `.ipynb` file and run the cells from top to bottom. Alternatively, upload a notebook to [Google Colab](https://colab.research.google.com/) to run it in your browser without any installation.
