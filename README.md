## About the Course

CSE110 is the introductory programming course offered by the Department of Computer Science and Engineering at BRAC University. It introduces the foundations of programming: control structures, string manipulation, arrays, file input/output, and debugging techniques, with the aim of preparing students to write fundamental programs with confidence.

### Course Outcomes

On completing the course, students are expected to be able to:

1. Use flowcharts and flow-control design tools, and write, debug, and execute programs.
2. Apply branching and looping structures, and manipulate text using string operations.
3. Create, read, modify, and sort arrays (lists) to store and process data.

For the official course description, objectives, and outcomes, see the [course page](https://cse.bracu.ac.bd/course/view/CSE110).

## Getting Started

### Option 1: Run in the browser (no installation)

1. Open any notebook in this repository on GitHub.
2. Replace `github.com` in the address bar with `githubtocolab.com` and press Enter.
3. The notebook opens in [Google Colab](https://colab.research.google.com/), where you can run every cell.

### Option 2: Run locally

**Requirements:** [Python 3.8 or later](https://www.python.org/downloads/), [Git](https://git-scm.com/downloads), and Jupyter Notebook.

```bash
# 1. Clone the repository
git clone https://github.com/ummasalmamim/BRACU_CSE110_Programming_Language-1_Introduction_to_Python.git
cd BRACU_CSE110_Programming_Language-1_Introduction_to_Python

# 2. Install Jupyter Notebook
pip install notebook

# 3. Launch Jupyter
jupyter notebook
```

Jupyter opens in your browser. Select a notebook and run its cells from top to bottom (**Shift + Enter** runs the current cell).
